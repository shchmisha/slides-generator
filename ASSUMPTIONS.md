# Допущения

Формат: что было неясно → что выбрали и почему → что изменится, если допущение неверно.

## Инфраструктура

1. **Порт веб-интерфейса.** В задании порт не указан → `8080` по умолчанию, меняется через `WEB_PORT` в `.env`. Если нужен другой порт, это правка одной переменной.
2. **Пароли внутренних сервисов.** Проверяющий копирует `.env.example` и вписывает только ключ LLM → в `.env.example` лежат пароли Postgres и Redis для локального запуска. Эти сервисы не публикуют порты наружу. Для продакшна пароли задаются в `.env`, код не меняется.
3. **Смена модели без пересборки.** «В настройках» трактуем как переменные окружения: правим `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY` в `.env` и выполняем `docker compose up -d`, контейнеры пересоздаются без пересборки образов. Если нужна смена из интерфейса, добавим страницу настроек администратора поверх той же конфигурации.
4. **Лимит загрузки.** До 10 файлов по 20 МБ → файлы загружаются по одному запросу на файл. nginx отклоняет тело больше 21 МБ кодом 413, приложение проверяет точный лимит и число файлов. Если потребуется пакетная загрузка, лимит nginx придётся поднять до ~205 МБ, и защиту от больших файлов будет держать только приложение.
