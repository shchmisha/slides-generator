# Fonts for layout

Gelasio has the same metrics as Georgia (the heading font of the test client's brand), so text
measured in the render container breaks into lines exactly as in PowerPoint with real Georgia.
Arial, Times New Roman and Courier New are covered by Debian's `fonts-liberation2`.
